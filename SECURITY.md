# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/andrzejsantocki/warsaw-ztm-hacs/security/advisories/new),
not in public issues. You can expect a first response within 7 days.

Never include your Warsaw Open Data API key or Home Assistant tokens in a report.
